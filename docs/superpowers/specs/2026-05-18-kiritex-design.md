# KiriTeX Design Spec

**Status:** active 1.0 design reference  
**Audience:** future agents and maintainers

## Purpose

KiriTeX is a XeLaTeX + ctex template for Chinese problem workbooks. It provides a compact A4 handout mode and a landscape Pad mode while keeping one source document syntax.

KiriTeX was separated from the sibling KazeTeX project. KazeTeX history may be used as design evidence, especially for robust logo construction, cover alignment, formula watermarks, and Pad navigation. It must not be treated as permission to restore KazeTeX-era APIs or legacy command names.

## Non-Negotiable Style Rules

### Automatic Numbering Only

KiriTeX owns visible numbering for sections, problems, and choice labels.

Do not manually duplicate numbers in semantic text:

- Use `\section{极限与连续}`, not `\section{第一章 极限与连续}` or `\section{1. 极限与连续}`.
- Use `\subsection{极限的计算}`, not `\subsection{1.1 极限的计算}`.
- Problem bodies must not start with `1.`, `题 1.1`, `第 1 题`, or similar labels.
- Subparts under one problem must use `problemsubparts`; do not hand-write `(1)`, `(2)`, etc.
- Choice contents must not include `A.`, `B.`, etc.; use `\choice{...}` and let the template label options.
- Multiple-choice prompts must not end with a period, question mark, Chinese full stop, Chinese question mark, or any other closing punctuation.
- Page headers, TOC entries, and cover metadata should not inject manual ordinal text unless that ordinal is part of the actual content.

This rule exists to avoid repeated output such as `1 第一章 ...`, `题 1.1 第 1 题 ...`, or `A. A. ...`.

### Logo

The `\KiriTeX` logo must render as mixed-case `KiriTeX`, never `KIRITEX`.

The TeX suffix has the vertical relation `T > X > E`:

- `T` is raised highest.
- `X` sits at the normal middle height.
- `E` is lowered and scaled smaller.

Use Latin Modern for the logo shape so it remains stable across Chinese fontsets.

## Document Modes

| Feature | A4 default | Pad mode |
| --- | --- | --- |
| Class option | `\documentclass{kiritex}` | `\documentclass[pad]{kiritex}` |
| Page shape | A4 portrait | 24 cm × 18 cm landscape |
| Body size | 五号 | 小四 |
| Problem flow | continuous | one problem per page |
| Intended use | print and PDF handout | tablet reading and annotation |

## Typography

- Western text uses Latin Modern Roman / Sans / Mono.
- Chinese text is delegated to ctex's platform fontset.
- Paragraph indentation is disabled; paragraph spacing is light and consistent.
- Section headings use navy and a rule below the title.
- Subsection headings use a quieter navy tone.

## Problem Environments

All problem types share the same counter, reset by `section`.

### `problem`

For calculation, proof, and short-answer prompts.

Expected output prefix: `题 <section>.<number>`.

### `problemsubparts`

For subparts inside a large problem. It uses `\item` and renders labels as `(1)`, `(2)`, etc. with English parentheses.

Subparts must sit normally at the left edge; do not introduce extra special indentation beyond the label spacing.

```latex
\begin{problem}
  计算下列极限：
  \begin{problemsubparts}
    \item ...
    \item ...
  \end{problemsubparts}
\end{problem}
```

### `\problemblock`

For fill-in blanks. The blank length is fixed:

```latex
\underline{\quad\quad\quad\quad\quad\quad}
```

Use `\problemblock` inside a sentence. Use `\problemblock*` at sentence end; the starred form appends an un-underlined Chinese full stop after the blank.

### `problemtf`

For true/false prompts. It shares numbering with `problem`; the author writes only the statement text. Do not append automatic parentheses, blanks, or rules after the question.

### `problemchoice`

For multiple-choice prompts. Authors write option content with `\choice{...}`. The environment stores options and renders labels automatically. The prompt text must end directly after its final word/formula, with no period or question mark. Do not append automatic parentheses, blanks, or rules after the options.

KiriTeX 1.0 does not provide legacy aliases for true/false or choice environments.

Layout policy:

- Measure the widest option.
- If it fits comfortably, render four options per row.
- If it is medium length, render two options per row.
- If it is long, render one option per row.
- Apply the same width-based rule to every supported option count from 2 to 8.

## Cover

The cover is generated by `\maketitle` and reads:

- `\title{...}`
- `\author{...}`
- `\date{...}`

Current cover language:

- Left navy band with `\KiriTeX` branding and quiet formula watermarks.
- Right-side title block with title, author, and date.
- A4 and Pad share the same visual identity and differ only by geometry.
- The logo and title block should align around the same vertical anchor.
- Avoid decorative subtitles that duplicate the project purpose; user-provided metadata is enough.

Do not add manual sequence numbers to cover metadata unless the sequence is part of a book title or official range name.

## Verification

After modifying class or style files, compile both demos twice:

```bash
xelatex -interaction=nonstopmode demo-a4.tex
xelatex -interaction=nonstopmode demo-a4.tex
xelatex -interaction=nonstopmode demo-pad.tex
xelatex -interaction=nonstopmode demo-pad.tex
```

Check that:

- both PDFs build without LaTeX errors;
- the logo reads `KiriTeX` and follows `T > X > E`;
- problem numbers are generated once;
- subparts use `(1)`, `(2)`, etc. and start from the left edge;
- fill-in blanks use the fixed `\problemblock` underline length;
- choice labels are generated once;
- true/false and multiple-choice questions have no automatic trailing parentheses, blanks, or rules;
- multiple-choice prompts have no closing punctuation;
- Pad mode still places each problem on a new page.
